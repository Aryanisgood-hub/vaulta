# Screenshots

Capture these on a phone using **Explore demo** (so no real club data appears), then save them here as PNG files and add them to the main `README.md`.

| File name | Screen |
| --- | --- |
| `01-home.png` | Home: balance, quick actions, Total spent and Reimbursements cards |
| `02-events.png` | Events list |
| `03-event-reimbursement.png` | An event page with the reimbursement section (e.g. TechFest 2026) |
| `04-reimbursements.png` | Reimbursements: left to use / left to receive |
| `05-charts-monthly.png` | Charts: monthly expenditure |
| `06-charts-events.png` | Charts: event-wise expenditure |
| `07-bill.png` | A bill with its receipt |
| `08-dark.png` | Any screen in dark mode |

Tip: use the same phone and the same theme for a consistent look, and 1080 px wide or narrower to keep the repository small.

Then add to `README.md`:

```markdown
## Screenshots
<p>
  <img src="docs/screenshots/01-home.png" width="220">
  <img src="docs/screenshots/03-event-reimbursement.png" width="220">
  <img src="docs/screenshots/05-charts-monthly.png" width="220">
</p>
```
